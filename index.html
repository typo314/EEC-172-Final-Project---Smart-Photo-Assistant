Project Description

For this project, we designed and built an interactive embedded camera system that allows a user to remotely trigger an image capture, display the captured image locally, and send image analysis data to the cloud. The main idea of the system is to combine sensing, embedded processing, and cloud communication in a standalone device. A user can press a button on a remote control to trigger the system. When the signal is received, the system captures an image using a camera module. The captured image is then displayed on an OLED screen so the user can see the result. At the same time, the system performs a simple brightness analysis on the image by measuring how dark different parts of the image are. The brightness data is then sent to AWS through the CC3200 WiFi module. AWS processes the data and sends a notification email that contains the brightness values of different regions of the image.
